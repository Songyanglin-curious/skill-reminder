# Agent Docs

Docs 是人和 AI 共用的持久项目上下文。从项目根 `AGENTS.md` 经 `docs/index.md` 进入相关主题，再结合当前代码、配置、测试和实际观察核实事实。

| 当前任务 | 入口 |
| --- | --- |
| 明确要求初始化、接入或改造 Docs | 按[初始化](references/initialize.md)盘点并建立或修复导航。已有实现需要调查并建立 Project 映射。 |
| 建立或核对 Project 当前系统映射 | 按 [Project 建模](references/project-model.md)调查整体与关键业务活动，综合实现、关系及限制，并用实际场景核对。 |
| 更新项目事实、设计决策、长期约定或可复用知识 | 按[维护](references/maintain.md)判断影响与授权，再更新相关原文及导航。 |
| 确定归属、目录、索引或证据位置 | 查[组织与导航](references/organization.md)中相关部分。 |

轮末先用当前上下文判断是否产生了值得保存的变化。仅确认了联调结果、运行行为或此前未知的限制，也可能需要核对 Project。用户禁止维护、没有实质变化、已有准确记录或不存在 `docs/index.md` 时直接结束。初始化须由用户明确提出；轮末提醒留给当前 Agent 检查既有 Docs，无需另起 Agent 或生成检查报告。

已读且仍适用的规则优先复用。按当前任务阅读或定位所需参考部分，避免在无变化时遍历全部模块。
