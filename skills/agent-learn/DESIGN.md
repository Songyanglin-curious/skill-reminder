# Agent Learn 设计

持续学习的交付是学习者能逐步建立、检验并修正解释模型。计划把这种理解的目标和知识依赖放到会话之外，让跨回合接续有一个稳定入口。每个专题用一份独立计划承载整体知识骨架和阶段路线，领域计划连接多个专题，进度快照记录当前在哪里以及如何继续。阶段与专题总结保存实际形成的认知，知识图示、练习或案例只有具备复用价值才需要独立保存。

## 从知识模型推导教学

知识模型回答各部分解决什么问题、怎样协同以及哪些关系决定了实际结果。学习路线据此选择入口和先后顺序。核心问题可以在多个阶段反复出现，每次提升解释深度、关系范围或应用能力。阶段规定预期能力与可观察的达成依据，教学围绕当前问题组织一批相关概念、机制和例子。这样的粒度既能把一个有意义的判断讲完整，也给学习反馈留出空间。

教学中的局部缺口走递归路径。每层补充都有一个要返回的问题，补到够用后逐层带回理解，最后回到阶段目标。遇到缺前置、阶段安排错误等结构性问题时，修订同一份计划和受影响的接续状态。改变学习目标或范围由学习者决定。

## 综合、证据与边界

阶段综合围绕该阶段的核心问题重建知识关系。专题结束时用最终版计划重新解释专题的核心问题，将各阶段成果连接成一个可独立使用的模型。两种总结都保留实际证据、适用边界和遗留缺口。已讲解、自述理解、解释或判断、独立应用有不同的证据要求，进度记录据此反映现状。

教学负责判断阶段能否收束并产出综合，资料维护负责补记已确定的变化。工作区根的 `.skill-reminder.json` 决定是否收到学习提醒。轮末 Hook 只传递一次短提醒，当前 Agent 依据任务、工作区与已有资料判断本轮是否需要补记。DSH 与 Codex 共用同一份 Skill 入口和按需参考资料。
