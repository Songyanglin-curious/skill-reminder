# 工作区与资料规格

学习资料保存在用户指定并授权的工作区。新建资料时复用现有命名和导航，从根 `index.md` 到领域索引，再到领域计划、进度和专题。新资料目录按需建立，索引只概括有意义的直接子级，使专题计划和成果可以逐层访问。

| 资料 | 职责 |
| --- | --- |
| 领域计划 | 保存领域目标、大致方向和专题入口。 |
| 专题计划 | 独立文档，保存专题目标、学习基础与范围、整体知识模型、分阶段教学路线和成果设计。按[规划规则](planning.md)建立或修订。 |
| 领域进度（如 `progress.md`） | 链接当前专题计划。记录当前阶段与问题、实际理解证据、接续动作、未解缺口和必要的分支返回点，以及已完成、暂挂或跳过的状态。保持快照，避免积累逐轮流水。 |
| 阶段总结 | 重建该阶段实际形成的模型、关系和边界，标明验证依据与缺口。 |
| 专题总结 | 从现行计划的目标和全局骨架出发，把阶段成果重新组织成可独立理解的整体。 |

用现行阶段名称或稳定链接定位状态。旧进度缺少阶段状态时，只据可确认的材料补齐，缺少依据的保留为未确认。阶段成果和最终总结可以写在同一文件的不同小节，按查阅需要再拆分；知识笔记、案例、图示和实践证据按复用价值保存。阶段、临时分支和未发生的成果无需预建文件。

如果已有专题路线分散在领域计划或进度里，在当前专题范围核实后提取独立计划，保留原入口和必要接续链接。先定位已有资料，再决定是否补充。

## 初始化与恢复

仅在用户明确要求建立或恢复持续学习工作区时执行。用户已指定目标和位置时直接复用；路径不明确且需要落盘时再询问。先检查指令、根索引和领域资料，保留有效入口与文件。补齐根与领域的 `index.md`、领域方向和学习进度；需要长期查阅时，在现有 `AGENTS.md` 增补从根索引恢复学习、按需调用 `agent-learn` 的简短导航。

轮末提醒的开关由工作区根的 `.skill-reminder.json` 管理，用户明确要求调整时通过插件配置入口处理。显式授权的教学或资料维护可以独立执行。

回读修改，简述入口和当前切入点。专题计划由[专题规划](planning.md)建立；初始化任务本身不展开课程。
