# 专题学习规划

在新建专题计划或结构性修订路线时使用。先建立可解释专题的知识模型，再据此设计学习路线。首次使用或需要重新对照时，阅读[完整规划范例](planning-example.md)，看同一个核心问题怎样贯穿不同学习层次。

## 1. 建立整体知识模型

- 明确专题的核心问题和最终能力，结合学习者的基础、用途和目标深度确定范围。缺少会改变路线的信息时再询问。
- 先从专题整体研究各部分为什么存在、解决什么问题。把知识按因果、依赖、分工或相互作用连起来，并说明这些联系怎样解释专题的核心问题。已有资料和指定教材用于核对机制与覆盖范围。
- 区分主干知识、支撑主干的必要前置，以及遇到具体需求时才深入的扩展内容。先形成解释得通的知识骨架，再开始划分阶段。

## 2. 设计螺旋上升的教学路线

- 选择一个能看见全貌的实际问题作为起点。先让学习者知道各部分在解决什么，再逐层深入关键机制、各部分如何协作，以及怎样用这套理解判断实际问题。
- 让核心问题或概念在后续阶段再次出现。明确本阶段复用了前面哪项理解，以及这次新增的解释深度、关联范围或应用能力。复用同一案例时，也要说明学习者这次能多解释、判断或完成什么。
- 用知识依赖说明为什么这样安排，把共同支撑一个判断的概念放在一起。一个阶段可包含多个问题，一次教学可组织一批相关内容。阶段数量按复杂度和学习者基础决定。
- 每阶段交代核心问题、预期理解或能力、主要内容及其关系、教学切入方式、学习深度、与前后阶段的联系、可观察的达成依据。用具体场景、对照或预测说明怎样引出关键关系。深度可区分目标中需要熟练运用、理解即可和了解即可的内容。用适合专题的形式表达，保留后续教学真正需要的细节。

## 3. 规划成果与调整方式

- 说明各阶段如何把实际形成的理解综合为可复用的成果。最终总结以现行计划的知识骨架和学习目标为依据，重组各阶段已经形成的认识，说明它们怎样共同回答专题问题，并指出证据和遗留缺口。计划里的达成依据用于指导教学，实际成果随教学发生后记录。
- 局部缺口按[教学规则](teaching.md#递归学习返回与路线修订)下钻，补到够用后返回。证据表明知识关系、先后顺序或阶段划分有问题时，修订同一份计划，说明受影响的阶段，按新路线继续。改变目标、范围或目标深度由学习者决定。

## 4. 检查并保存

保存前从学习者视角核对三项：

- **脉络清晰**。看完整体模型，能说出各部分如何配合，以及阶段顺序为什么有用。
- **螺旋上升**。能指出后续阶段重新使用了哪项核心理解，以及因此新增的解释、关联或应用能力。
- **粒度合理**。每个阶段围绕一个有边界的理解或能力，相关知识可一起组织。有一个明确的切入问题，后续讲解能据此开始。

把整体模型、阶段路线和成果设计保存到同一份独立专题计划，按[资料规格](spec.md)建立导航。`progress.md` 只保存当前位置和接续状态。把计划写到足以组织教学的深度，具体讲解随学习展开。先完成规划和可行的落盘，再说明整体结构、阶段安排及其理由。用户只要求规划时，到此结束；已经明确要开始学习时，再从计划的切入问题开始。
