# 学习资料维护

只保存教学或显式学习任务中已确定、已发生且尚未记录的实质变化。普通任务、用户要求不记录、无需长期保存或已经记录时直接结束。

轮末补漏时，从上下文定位本轮已有授权的学习工作区，核对根索引与启用标记，详见[工作区规格](workspace.md)。只核对当前学习范围；找不到确认的工作区时直接结束，无需向上或跨领域搜索。显式维护按用户指定范围。

| 已经发生的变化 | 维护动作 |
| --- | --- |
| 专题计划建立或路线修订 | 保存独立计划或更新原计划，补齐导航。对照现行计划修复阶段引用。 |
| 当前阶段、问题、证据、缺口、接续点或阶段状态改变 | 更新进度快照。切换专题时保留未完成专题的接续信息；已解决的临时分支从活跃缺口移除。 |
| 已经形成阶段或专题综合 | 保存实际成果并复用适合的原文。一次讲解结束、补缺结束或只有阶段收束判断时，最多记录实际变化，维护阶段无需代写教学综合。 |
| 记录与证据或现行计划不符 | 校正状态或链接，明确已讲解、自述理解、已能解释或判断、可独立应用的证据差异。没有学习者反馈时，理解留待确认，接续点保留在现有问题。 |

写入前回读相关原文，根据实际变化最小修改，回读结果和受影响链接。迁移、删除重要资料或改变长期目标需用户明确授权。轮末检查不发起教学、新评测、初始化或再次续接。路径、权限或其他条件阻止写入时简述未完成事项；有修改时简述关键变化，无变化时直接结束。
