# 项目定位与学习闭环设计

早期的学习对话需要用户不断说「继续」或「记录一下」，教学接续、状态保存和成果整理都靠用户逐项推动。Agent Learn 希望让 AI 承担既定目标内的教学组织和资料维护，让学习者保有方向、范围、深度和节奏的决定权。一次普通答疑可以直接完成。持续学习则需要跨回合建立、检验和修正一个能够解释实际问题的知识模型。[agent-learn 初版设计](https://github.com/Songyanglin-curious/agent-learn/blob/dc9f6bb3ba4e45fc674e48eeed1ff3f0f888a9ba/docs/design/项目定位与学习闭环设计.md)

## 从知识关系推导路线

早期方案以小单元推进，重视追问的返回位置和自然停顿。后来把独立专题计划作为主线，以阶段要形成的理解或能力组织教学。一个阶段可以覆盖多个相互依赖的知识点，一次讲解尽量说完整一个有意义的判断，再根据反馈决定是否继续。[agent-learn 设计演变](https://github.com/Songyanglin-curious/agent-learn/blob/dc9f6bb3ba4e45fc674e48eeed1ff3f0f888a9ba/docs/design/index.md)

- 从一个能看见全貌的实际问题切入。先解释各部分的分工、依赖或因果关系，再据此确定阶段顺序。后续阶段重用同一核心认识，每次增加可解释的机制、关系范围或应用能力。[专题规划规则](../references/planning.md)
- 学习者有追问时，先处理追问。遇到局部缺口就递归补到够用，再把所得理解带回原问题。发现缺少前置知识、阶段划分不当或顺序有误时，修订同一份计划及受影响的接续状态。[教学规则](../references/teaching.md)
- 依据实际表现判断进度。分别记录已讲解、学习者自述理解、能够解释或判断、能够独立应用。确认程度影响后续时，可以用简短的新场景检验。当前问题闭合时可以停住，学习者明确要求继续时从已有接续点展开。[学习原则](../references/principles.md)

## 让学习可以跨会话接续

领域计划提供专题入口，独立专题计划保存知识骨架、阶段路线和预期成果，进度快照记录当前位置、暂挂事项及接续动作。阶段总结围绕本阶段的问题重建知识关系。专题总结依据现行计划重新组织各阶段成果，使读者可以独立理解专题的核心问题、机制和适用边界。案例、图示与练习有复用价值时再单独保存。[学习资料规格](../references/spec.md)

教学负责决定阶段如何收束、综合哪些成果。维护负责补记已发生的状态变化和已经形成的成果。轮末 Hook 给当前 Agent 一次回查机会。这套分工延续了初版的轻量取舍，DSH 与 Codex 在本仓库共用 Skill 和学习规则，提醒交由 `skill-reminder` 处理。[维护规则](../references/maintain.md) [接入与维护注意事项](接入与维护注意事项.md)
