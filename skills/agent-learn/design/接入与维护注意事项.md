# 接入与维护注意事项

## 共享 Skill 与轮末提醒

- 学习任务由当前 Agent 通过 `agent-learn` Skill 处理。按任务读取所需规则，已读且仍适用的内容继续复用。工作区初始化以用户的明确要求为起点，学习资料保存在用户指定且已授权的工作区。[Skill 入口](../SKILL.md)
- `skill-reminder` 从会话目录定位最近的 Git 根，无 Git 时使用会话目录。该目录的 `.skill-reminder.json` 中 `skills.agent-learn` 设为 `true` 时启用学习提醒。当前 Hook 按事件边界和配置投递短提醒，普通答疑即使收到提醒，也由当前 Agent 判断是否有实际学习变化需要补记。[提醒配置实现](../../../src/workspace-config.mjs) [提醒组装实现](../../../src/reminders.mjs) [学习提醒文案](../../../prompts/agent-learn.md)
- DSH 对每个会话的轮次去重，并跳过已取消和子 Agent 的回合。Codex 通过 `stop_hook_active` 避免同一轮反复续接。回查时以已确认的学习事实为依据，状态已保存或没有实质变化即可结束。阶段收束、评估或综合由教学流程处理。[DSH Hook](../../../src/index.mjs) [Codex Hook](../../../src/codex-stop.mjs) [维护规则](../references/maintain.md)

## 旧插件迁移时的核对项

旧 DSH 插件用当前目录的 `.agent-learn.json` 和 `index.md` 确认启用，并用 `agent_learn_rules(mode="teaching")` 登记可提醒的教学轮次。旧 Codex 插件也使用该标记，并在 `SessionStart` 提示加载 Skill。现有共享 Skill 通过自身的 `references/` 读取规则，提醒使用 `.skill-reminder.json`。迁移时先核对加载的是哪一份同名 Skill，再验证真正生效的 Hook。切换成功后，按实际安装情况停用旧提醒，避免同一轮收到两套提示。[旧 DSH 实现](https://github.com/Songyanglin-curious/agent-learn/blob/dc9f6bb3ba4e45fc674e48eeed1ff3f0f888a9ba/docs/project/实现与使用说明.md) [旧 Codex 实现](https://github.com/Songyanglin-curious/agent-learn/blob/dc9f6bb3ba4e45fc674e48eeed1ff3f0f888a9ba/docs/project/Codex插件.md) [本仓库接入说明](../../../README.md#验证与迁移)

当前 `spec.md` 的工作区启用一节和 `init.md` 的初始化步骤仍含旧标记及工具说明。共享 Skill 的加载入口以 `SKILL.md` 的兼容性说明为准，轮末启用条件以本仓库配置和 Hook 实现为准。旧段落保留在规则中，后续调整规则时一起核对初始化、提醒配置与资料规格。[资料规格](../references/spec.md#工作区启用) [初始化规则](../references/init.md) [兼容性说明](../SKILL.md#6-兼容性说明)

早期 DSH 插件曾把随包默认规则补到用户目录。自 0.1.1 起默认读取安装包内的规则，显式自定义目录里的既有文件继续保留。排查旧安装时先回读实际规则路径与版本，升级包和自定义规则是两条独立的更新路径。[旧 DSH 规则定位](https://github.com/Songyanglin-curious/agent-learn/blob/dc9f6bb3ba4e45fc674e48eeed1ff3f0f888a9ba/docs/project/实现与使用说明.md#规则工具)
