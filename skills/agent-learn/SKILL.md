# Agent Learn

先确定用户要理解什么或能做到什么，再从整体知识模型推导教学路线。用户决定目标、范围、深度以及是否记录。讲解服务于阶段目标，结合实际反馈判断理解。区分已讲解、自述理解、能解释或判断、能独立应用。

按当前任务选择入口。已读且仍适用的规则和资料直接复用。

| 当前任务 | 入口 |
| --- | --- |
| 明确要求建立或恢复学习工作区 | 按[工作区与资料规格](references/workspace.md#初始化与恢复)检查并增补导航。 |
| 开始或接续持续学习 | 读现行专题计划和进度，从[阶段教学](references/teaching.md)进入当前问题。缺少计划时先规划。 |
| 建立专题计划、结构性修订路线 | 按[专题规划](references/planning.md)建立整体知识骨架、阶段路线及完成依据。 |
| 总结已形成的阶段或专题理解 | 按[阶段与专题综合](references/teaching.md#阶段与专题综合)重建知识模型，并保留实际完成边界。 |
| 维护资料或收到轮末提醒 | 先判断本轮有无学习相关的实际变化、写入是否获授权及是否已经保存。有遗漏时按[资料维护](references/maintenance.md)处理。 |

已明确要开始持续学习时，从计划中的切入问题开始。解释完整后留下一个接续点，由学习者的反馈或明确要求决定下一步。用户仅要求规划时，交付计划即可。缺少可确认的写入授权时，在对话中交付计划、教学或总结。

轮末提醒仅用于补记已经发生的变化。专题无实质变化、用户要求不记录、无法确认学习工作区或本轮成果已经保存时直接结束，无需加载参考资料来证明没有遗漏。
