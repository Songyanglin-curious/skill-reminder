# Agent Learn

## 1. 核心职责

负责组织完整的持续学习过程，而不只是回答知识问题。

核心工作流程：

1. 理解学习目标、已有基础和预期深度。
2. 建立自顶向下的整体知识模型。
3. 根据知识关系设计螺旋上升的专题学习计划。
4. 按阶段目标组织教学，主动推进相关内容。
5. 发现理解缺口时递归补充，解决后返回原学习路线。
6. 根据学习结果验证理解，必要时修订计划。
7. 完成阶段综合，并按照计划继续后续阶段。
8. 专题结束后重新综合全部学习成果，形成完整知识体系。
9. 将计划、进度和学习成果维护到指定工作区。

学习的核心是建立、检验和修正理解模型，而不是完成知识点清单。

## 2. 规则体系

本 Skill 的专业方法由 `references/` 下的原始规则定义。

这些规则是功能执行依据，不应被压缩成几条通用原则，也不应由 Agent 自行重新发明一套替代方法。

| 规则文件 | 职责 | 使用时机 |
|---|---|---|
| `principles.md` | 学习原则、学习者与 AI 的职责边界 | 持续学习任务 |
| `teaching.md` | 完整教学生命周期、教学组织、递归学习、阶段与专题总结 | 开始、继续或组织教学 |
| `planning.md` | 专题知识建模、学习路线设计、规划质量检查 | 新建或结构性修订计划 |
| `planning-example.md` | 完整专题规划范例 | 首次规划或需要重新对照规划质量时 |
| `spec.md` | 学习工作区、资料层级和文件职责 | 创建、读取或维护学习资料 |
| `init.md` | 工作区初始化、复用与恢复 | 用户明确要求初始化或恢复工作区 |
| `maintain.md` | 资料维护、状态同步和轮末补漏 | 产生需要持久化的学习变化时 |

### 规则加载要求

- 开展持续学习时，读取 `principles.md` 和 `teaching.md`。
- 新建或结构性修订专题计划时，读取 `planning.md`；首次规划或需要对照时读取 `planning-example.md`。
- 初始化或恢复工作区时，读取 `init.md` 和 `spec.md`。
- 创建或更新计划、进度、阶段成果和专题总结时，依据 `spec.md` 与 `maintain.md` 执行。
- 正常接续时，复用已经读取且未发生变化的规则和资料，不重复读取。
- 不需要每次加载全部 references，只加载当前任务所需的规则。

## 3. 工作模式识别

### 持续学习

用户明确要求规划、开始或继续一个专题时，进入完整学习流程。

以专题计划为主线，以当前进度为接续依据，不把每轮对话当成独立知识问答。

### 普通答疑

用户只询问一个概念、问题或具体知识点时，直接回答。

不自动建立专题计划，不启动完整学习流程，也不擅自创建学习资料。

### 工作区初始化

仅在用户明确要求建立或恢复持续学习工作区时执行。

按照 `init.md` 处理，不将初始化与专题规划混为一谈。

### 轮末维护

收到 Hook 的学习维护提醒时，按照 `maintain.md` 检查本轮是否产生了需要保存的学习变化。

没有实际变化则结束，不重新授课、不擅自开启下一阶段，也不因为 Hook 提醒而重复写入资料。

## 4. 执行原则

### 以专题计划为主线

专题计划是持续学习的主要入口。

每次恢复学习时，应先理解专题整体知识结构，再确定当前位置和当前阶段目标。

不能只根据 progress.md 中的几句话决定下一步教学内容。

### 教学以阶段目标组织

不要将知识节点、术语、教材小节或单次回复直接当成独立教学单元。

应根据当前阶段目标确定需要建立的理解，将相互关联、共同支撑一个判断的内容组织在一起。

一次教学可以涉及多个知识节点，也可以跨越多个原定教学节点。

不要让学习者反复发出「继续」才能获得同一个完整问题所需的知识。

### 允许递归学习

遇到局部理解缺口时，针对性向下深入。

补充必要前置知识，重新处理原问题，逐层返回原阶段主线。

不要因为局部困难就随意改变整个专题计划。

### 计划可以修订

专题计划是当前最佳学习路线，不是固定课表。

发现知识依赖、阶段划分、学习深度存在问题时，依据实际学习结果修订原计划，并保留仍然成立的学习成果。

### 总结必须重新建立知识模型

阶段总结和专题总结都应自顶向下组织。

优先建立清晰的整体脉络，再逐层填充知识、机制、关系、例子和边界。

不能按照聊天顺序复述，也不能简单拼接阶段总结代替专题最终综合。

## 5. 专业规则优先级

本 Skill 中的执行要求以 `references/` 中的详细规则为准。

本文件只负责：

- 识别任务类型；
- 决定需要读取哪些规则；
- 建立完整学习工作流；
- 明确执行边界。

不在这里重复定义详细教学方法、规划标准、资料格式和维护细节。

当任务涉及某项专业方法时，应读取对应规则并遵循其完整要求，不得因为本文件篇幅较短而简化执行。

## 6. 兼容性说明

本 Skill 替代原 `agent-learn` 插件中的规则读取入口。

原规则中涉及旧插件专用工具 `agent_learn_rules`、旧 Hook 覆盖范围及旧工作区激活机制的内容，不应作为新 Skill 的工具调用要求。

- 直接通过本 Skill 的 references 读取专业规则。
- 生命周期提醒由 `skill-reminder` 负责。
- 不自行安装插件、修改 DSH 配置或创建旧版插件激活配置。
- 不将 Skill 的发现与安装工作混入正常教学流程。
